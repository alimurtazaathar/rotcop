# Rotcop

You save reels, posts and videos constantly. You almost never go back. The save
*feels* like progress and isn't.

Rotcop is anti-**limbo**, not anti-saving. Every saved link is understood once,
reduced to a short **Recap** and a concrete **Action Item**, and then has to go
somewhere: Acted On, Kept, or Archived. The goal is that you never reopen the
original.

Built for the Firebase `#BuildHybridAI` hackathon on **Firebase AI Logic hybrid
inference**, under one rule:

> **The cloud reduces media to text. The device turns text into meaning.**

The only thing ever sent to a cloud model is a public video URL. Your notes,
categories and recaps are understood on your own machine.

See [`GLOSSARY.md`](./GLOSSARY.md) for the domain vocabulary and
[`docs/adr/`](./docs/adr) for the decisions behind the architecture.
